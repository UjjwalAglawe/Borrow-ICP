# 💎 AssetTokens – Fractional NFT Marketplace

AssetTokens is a decentralized platform that empowers users to **mint**, **fractionalize**, and **trade NFTs** with ease. It leverages blockchain technology to provide transparency, ownership, and liquidity to digital assets.

![AssetTokens Preview](https://yellow-top-donkey-485.mypinata.cloud/ipfs/bafybeie64rdm24z7mpejiv674rmu4lkhk35s3pdkwigfu7whflcnq7nueq)

---

## 🚀 Features

- 🖼️ Upload images and mint NFTs on-chain
- 🧩 Fractionalize ownership of NFTs into any number of parts
- 🛒 List and trade fractionalized NFTs
- 🔐 MetaMask wallet integration
- 📜 Transparent smart contracts powered by Solidity

---

## 🔧 Tech Stack

**Frontend:**
- React.js / Next.js
- Tailwind CSS
- Ethers.js
- IPFS via Pinata

**Backend / Blockchain:**
- Solidity (Smart Contracts)
- Hardhat
- Ethereum-compatible network (Celo Alfajores / Mumbai Testnet)
